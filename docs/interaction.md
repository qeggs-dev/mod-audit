# 交互说明

## 节点图怎么读

- **中间的大卡片是模组加载器**（根节点），四周是各个 mod。每条从根出发的线 = 这个 mod 已被它加载。
- **一个卡片 = 一个 mod**：顶部彩色高亮条 = 加载器（蓝 Fabric / 橙 NeoForge / 绿 Forge / 紫 多加载器通用包），下方灰区显示 `N 注入 · N 类` / `代码大小` / 模组概要。右侧小点表示该 mod 有高危问题。
- **卡片之间没有拉力。** 边只是视觉连线，不参与受力；位置是自动排版（黄金角螺旋，加载到谁就先占下一个位置）。只有被拖的卡片会动，其它卡片只会被碰撞推开。
- 四种线：**实线红** = 可能抢同一条指令或 `@Overwrite` 重叠；**实线橙** = 方法体可能被换掉、别人还锚在具体指令上；**实线灰** = 静态上看可共存；**虚线绿** = 前置依赖（A 需要 B）。线粗 ≈ 重合处数。线是算出来的，不能拆。
- 判定只看「两个 mod 之间」：按注入器对目标的所有权分类（`CLAIM`）＋ `@At` 的 `(value, target, ordinal)` 三元组是否相同。单模组自身的问题（mixin 类缺失、版本区间不符）降为提示。

## 视图操作

- 拖卡片 = 直接移动；滚轮 = 以鼠标为中心缩放；拖空白 = 平移；双击空白 = 自适应；Esc = 取消选中。
- **摄像机自动取景**：缓慢把镜头和缩放拉到「刚好装下所有卡片」。一旦手动缩放或平移就自动解绑，右上角按钮可重新开启。
- **左上角搜索**：按 `modId` / jar 文件名 / 概要匹配，命中的加蓝框、其余压暗到 10%。回车把镜头移到命中簇并选中第一个，Esc 清空。
- **右上角 `外观`** 可调发光 / 描边 / 连线宽度，存 localStorage，可一键恢复默认。
- 分析过程中卡片与连线是边算边长出来的，不是等全部算完才出现。
- 点卡片 → 右侧列出修改清单；每条下面折叠着「还有哪些 mod 也改这里」，点进去可直接跳到那个 mod。

## 筛选与高亮

- **图例可多选**：告警等级、标签颜色（加载器）两组都能叠加，按并集筛选；未选中的类型压暗到 7%，再点一次取消。
- **顶部三个统计可点**：`mod` 在资源管理器打开 mods 目录（仅桌面版）、`注入点` 打开注入点分析面板、`高危` 高亮所有含高危内容的节点（点空白处取消，连线跟随端点一起淡出）。
- **注入点面板**：按类名 / 方法 / 模组 / 注入类型过滤；选中条目后列表收窄为「左列表 + 右卡片」，再选只换卡片。展示的是注解级结构（`@Mixin` / `@Inject` / `@At` 的声明值），不是反汇编字节码。
- **版本统计面板**：MC 版本按区间画条（纵轴是名次坐标，没有覆盖的区间会被压缩），交集叠在每行的条上显示；Java 只给「最高要求 + 是否满足实例声明」的结论。

## 面板通用交互

- 点空白：注入点在详情页时回到列表；版本统计不做任何事。
- **双击空白关闭**，右上角按钮关闭，Esc 逐级回退。

## 导出报表

右上角 `导出精简` / `导出全量`；命令行等价 `--export <文件>`（加 `--lite` 为精简档）。

英文，按严重度分节、用表格压行数。**全量**不截断（含 Mermaid 关系图与类名修改表，Create 的 140 mod 约 58 KB），**精简**只留关键部分（约 20 KB）。开头写明「静态推测，不是运行时事实」，结尾附 `grading rules` 说明分级依据。
